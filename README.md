# Fin Ops (F-Ops)

Web app pencatatan dan pemantauan keuangan pribadi. Pengguna memasukkan transaksi melalui UI, lalu backend mengurai, mengklasifikasikan, meminta konfirmasi bila perlu, dan menyimpannya ke database.

## Dokumen

- [PRD](docs/PRD.md): masalah, pengguna, MVP, kebutuhan, dan kriteria keberhasilan.
- [Desain](docs/DESIGN.md): alur UI/UX, arsitektur, model data, API, keamanan, dan keputusan teknis awal.
- [Instruksi agent](.github/agents/expense-orchestrator.agent.md): ruang lingkup dan perilaku agent klasifikasi.
- [Skill](.agents/skills/finops-expense-intake/SKILL.md): prosedur pemrosesan input transaksi.
- [AGENTS.md](AGENTS.md): aturan kerja untuk agent yang mengubah repo ini.
